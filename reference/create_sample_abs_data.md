# Create Sample Loan-Level Data

Internal generator for
[`sample_abs_data`](https://ambientpointcorp.github.io/oasr/reference/sample_abs_data.md).
Kept in the package so the dataset can be regenerated and so the
amortisation that produces `balance` is on the record.

## Usage

``` r
create_sample_abs_data()
```

## Value

A data frame of twelve loans.
