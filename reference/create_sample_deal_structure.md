# Create Sample Deal Structure

Internal generator for
[`sample_deal_structure`](https://ambientpointcorp.github.io/oasr/reference/sample_deal_structure.md).
Sizes the tranches off
[`create_sample_abs_data`](https://ambientpointcorp.github.io/oasr/reference/create_sample_abs_data.md)
so the two datasets cannot drift apart.

## Usage

``` r
create_sample_deal_structure()
```

## Value

A list with bonds and waterfall components.
