# Plot Method for OAS Surface Analysis

Creates plots to visualize OAS surface analysis results.

## Usage

``` r
# S3 method for class 'oas_surface'
plot(x, type = "oas", ...)
```

## Arguments

- x:

  An object of class "oas_surface"

- type:

  Character. Type of plot: "oas", "price", "wal", or "all"

- ...:

  Additional arguments (not used)

## Value

A ggplot object or list of ggplot objects
