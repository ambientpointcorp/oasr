# Plot Method for OAS Result

Creates plots to visualize the OAS analysis results.

## Usage

``` r
# S3 method for class 'oas_result'
plot(x, type = "cashflows", ...)
```

## Arguments

- x:

  An object of class "oas_result"

- type:

  Character. Type of plot to create: "cashflows", "rates",
  "prepayments", or "all"

- ...:

  Additional arguments (not used)

## Value

A list of ggplot objects
